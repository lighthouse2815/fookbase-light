# Fookbase V1.2.0

## Bảo mật phiên đăng nhập

- Web, Admin và Zola Light chuyển refresh token khỏi `localStorage` sang cookie
  `HttpOnly`, `SameSite=Lax`, `Path=/api/auth` và `Secure` trên HTTPS.
- Mỗi browser client có cookie riêng để tránh ghi đè phiên giữa Fookbase Web,
  Admin Center và Zola Light.
- Refresh cookie chỉ được đọc khi có transport header hợp lệ; client mobile và
  API client cũ vẫn giữ hợp đồng refresh token trong JSON.
- Refresh rotation, đăng xuất, đăng ký, 2FA, Google login và đổi mật khẩu đều
  cập nhật cookie browser tương ứng.
