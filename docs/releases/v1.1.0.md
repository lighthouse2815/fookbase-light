# Fookbase V1.1.0

## Cải thiện chính

- Sửa liên kết sâu thông báo: bài viết, bình luận và sự kiện mở đúng nội dung đích; nội dung không còn quyền xem hiển thị trạng thái an toàn.
- Cải thiện danh sách cảm xúc: phân trang có giới hạn, lọc theo loại cảm xúc, trạng thái kết bạn và loại trừ quan hệ block hai chiều.
- Hoàn thiện tương tác bình luận: reaction, trả lời một cấp, chỉ báo đang trả lời và tác giả bình luận được trả theo projection chung.
- Hiển thị số lượt chia sẻ và cập nhật số liệu ngay sau khi chia sẻ thành công.
- Zola Light dùng dialog tìm thành viên thay cho UUID/prompt; các thao tác đổi tên, sửa/gỡ tin và rời nhóm có dialog phù hợp.
- Đồng bộ thêm giao diện tiếng Việt cho Events và Photos/Albums; giảm tải URL media bằng lazy loading; dọn dữ liệu demo không dùng.

## Xác minh

- `frontend/web`: lint và production build thành công.
- `frontend/zola-light`: lint và production build thành công.
- Backend biên dịch thành công. Integration test cần chạy lại trong CI hoặc môi trường có runtime `Microsoft.AspNetCore.App 10.0.0`; môi trường chuẩn bị release hiện tại chỉ có SDK nên test host không khởi chạy được.

## Ghi chú bảo mật hoãn lại

Access/refresh token hiện còn được lưu trong localStorage. Việc chuyển refresh token sang HttpOnly Secure SameSite cookie là một milestone bảo mật riêng, tác động Identity API, refresh rotation, CORS, cả ba frontend, 2FA, logout và session revocation; không nằm trong V1.1.
