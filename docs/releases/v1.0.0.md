# Fookbase V1.0.0

Fookbase V1 phát hành modular monolith ASP.NET Core với PostgreSQL, private MinIO, SignalR và ba React application: web, Zola Light và admin.

## Highlights

- Social/profile: profile, friendship/follow, posts, comments, reactions, saves, shares và media riêng tư.
- Feed Ranking V2 với privacy-aware ranking, cùng Search, Groups và Pages.
- Messenger qua Zola Light, Reels, Stories, Events, Photos/Albums, Memories và Birthdays.
- Privacy, account security/2FA, moderation và production hardening: explicit CORS, health/readiness, backups và Data Protection key ring.

## Production limit

Fookbase V1 supports **one API instance**. SignalR and Zola Light presence are process-local; this release does not claim horizontal API scaling.
